# FGS Core Database Tables (Final V1)

This document defines the finalized core database tables for the FGS FSM SaaS platform.

Naming Convention:
- All tables use PascalCase.
- All platform tables use `Fgs` prefix.
- **Global catalogs** (no `TenantId` / `CompanyId`) use the **`Glo`** prefix (e.g. `GloBusinessType`, `GloLanguage`).
- **Tenant- or company-scoped setup** rows use the **`FgsSetup`** prefix.

Architecture Principles:
- Primary relational database is **PostgreSQL** (DDL examples below use PostgreSQL types and syntax).
- Multi-tenant SaaS architecture.
- One Tenant can own multiple Companies.
- Company stores identity/branding.
- CompanyConfiguration stores operational FSM behavior.
- Addresses are reusable and stored in `FgsLocation`.
- Credentials/secrets use AWS Secrets Manager.
- PostgreSQL stores metadata only.
- Use UTC timestamps everywhere.
- Use `IsActive` instead of physical deletion.
- In PostgreSQL DDL below, **PascalCase tables and columns are double-quoted** so names are stored case-sensitively (e.g. `"FgsTenant"`, `"TenantCode"`).

# 1. FgsTenant

Purpose:
Represents the top-level SaaS customer/account.

Examples:
- ABC Holdings
- NorthStar Services
- Acme Franchise Group

## Table Structure

```sql
CREATE TABLE "FgsTenant"
(
    -- Primary GUID identifier for tenant.
    -- Used internally and externally in APIs/integrations.
    "Id" uuid PRIMARY KEY,

    -- Short unique tenant code.
    -- Example: ACME, NORTHSTAR
    "TenantCode" varchar(50) NOT NULL,

    -- Friendly/business display name.
    "Name" varchar(200) NOT NULL,

    -- Registered legal company name.
    "LegalName" varchar(300) NULL,

    -- Main contact email.
    "Email" varchar(300) NULL,

    -- Main contact phone number.
    "PhoneNumber" varchar(50) NULL,

    -- Company website.
    "Website" varchar(500) NULL,

    -- Physical/business location address.
    "PhysicalLocationId" uuid NULL,

    -- Billing/remit-to/mailing address.
    "BillingLocationId" uuid NULL,

    -- Subscription plan reference.
    "SubscriptionPlanId" INT NULL,

    -- Default timezone for tenant.
    "TimeZone" varchar(100) NULL,

    -- Default currency.
    "DefaultCurrency" varchar(20) NULL,

    -- Default language.
    "DefaultLanguageId" INT NULL,

    -- Active/inactive status.
    "IsActive" boolean NOT NULL DEFAULT TRUE,

    -- Audit fields.
    "CreatedOn" timestamptz NOT NULL DEFAULT (timezone('utc', now())),
    "CreatedBy" uuid NULL,

    "UpdatedOn" timestamptz NULL,
    "UpdatedBy" uuid NULL,

    CONSTRAINT "FK_FgsTenant_PhysicalLocation"
        FOREIGN KEY ("PhysicalLocationId")
        REFERENCES "FgsLocation"("Id"),

    CONSTRAINT "FK_FgsTenant_BillingLocation"
        FOREIGN KEY ("BillingLocationId")
        REFERENCES "FgsLocation"("Id"),

    CONSTRAINT "FK_FgsTenant_GloLanguage"
        FOREIGN KEY ("DefaultLanguageId")
        REFERENCES "GloLanguage"("Id")
);
```

# 2. FgsTenantCompany

Purpose:
Represents an operational business entity under a Tenant.

Examples:
- ABC Plumbing
- ABC HVAC
- ABC Electrical

IMPORTANT:
This table stores:
- identity
- branding
- business information

Operational FSM settings belong in:
`FgsTenantCompanyConfiguration`

## Table Structure

```sql
CREATE TABLE "FgsTenantCompany"
(
    -- Internal identity column.
    "Id" bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

    -- Public GUID used in APIs/integrations.
    "CompanyGuid" uuid NOT NULL,

    -- Parent tenant.
    "TenantId" uuid NOT NULL,

    -- Internal business/company number.
    "CompanyNumber" BIGINT NOT NULL,

    -- Business category.
    "BusinessTypeId" INT NOT NULL,

    -- Unique company code.
    "Code" varchar(100) NOT NULL,

    -- Display/business name.
    "Name" varchar(200) NOT NULL,

    -- Legal registered name.
    "LegalName" varchar(300) NULL,

    -- Contact email.
    "Email" varchar(300) NULL,

    -- Contact phone number.
    "PhoneNumber" varchar(50) NULL,

    -- Website URL.
    "Website" varchar(500) NULL,

    -- Tax registration number.
    "TaxId" varchar(100) NULL,

    -- Physical/business address.
    "PhysicalLocationId" uuid NULL,

    -- Billing/remit-to address.
    "BillingLocationId" uuid NULL,

    -- Branding assets.
    "FullLogoUrl" varchar(1000) NULL,
    "CompactLogoUrl" varchar(1000) NULL,
    "IconLogoUrl" varchar(1000) NULL,
    "FaviconUrl" varchar(1000) NULL,

    -- Active/inactive status.
    "IsActive" boolean NOT NULL DEFAULT TRUE,

    -- Audit fields.
    "CreatedOn" timestamptz NOT NULL DEFAULT (timezone('utc', now())),
    "CreatedBy" uuid NULL,

    "UpdatedOn" timestamptz NULL,
    "UpdatedBy" uuid NULL,

    CONSTRAINT "FK_FgsTenantCompany_Tenant"
        FOREIGN KEY ("TenantId")
        REFERENCES "FgsTenant"("Id"),

    CONSTRAINT "FK_FgsTenantCompany_GloBusinessType"
        FOREIGN KEY ("BusinessTypeId")
        REFERENCES "GloBusinessType"("Id"),

    CONSTRAINT "FK_FgsTenantCompany_PhysicalLocation"
        FOREIGN KEY ("PhysicalLocationId")
        REFERENCES "FgsLocation"("Id"),

    CONSTRAINT "FK_FgsTenantCompany_BillingLocation"
        FOREIGN KEY ("BillingLocationId")
        REFERENCES "FgsLocation"("Id")
);
```

# 3. FgsTenantCompanyConfiguration

Purpose:
Stores operational FSM settings and behavior.

IMPORTANT:
Do NOT place operational settings inside `FgsTenantCompany`.

This table stores:
- numbering rules
- overtime rules
- portal/widget settings
- accounting integration settings
- dispatch behavior
- auto-arrival rules
- billing rules

## Table Structure

```sql
CREATE TABLE "FgsTenantCompanyConfiguration"
(
    -- Composite key.
    "TenantId" uuid NOT NULL,
    "CompanyId" BIGINT NOT NULL,

    -- Technician time tracking behavior.
    "TimeCardOptionId" INT NOT NULL,

    -- Accounting integration type.
    "AccountingIntegrationTypeId" INT NULL,

    -- Portal/widget feature flags.
    "EnableCallBookingWidget" boolean NOT NULL DEFAULT TRUE,
    "EnablePaymentWidget" boolean NOT NULL DEFAULT TRUE,
    "EnableCustomerPortal" boolean NOT NULL DEFAULT TRUE,
    "EnableRulesManagement" boolean NOT NULL DEFAULT FALSE,

    -- Auto-arrival settings.
    "EnableAutoArrive" boolean NOT NULL DEFAULT FALSE,

    -- Radius in meters.
    "WorkLocationRadiusForAutoArrive" INT NULL,

    -- Overtime configuration.
    "OTStartTime" time NULL,
    "OTEndTime" time NULL,

    -- Double-time configuration.
    "DTStartTime" time NULL,
    "DTEndTime" time NULL,

    -- Billing calculation behavior.
    -- Example values:
    -- DISPATCH
    -- ARRIVE
    "BillHoursFromDispatchOrArrive" varchar(20) NOT NULL,

    -- Source code requirements.
    "SourceCodeRequiredOnWorkOrder" boolean NOT NULL DEFAULT FALSE,
    "SourceCodeRequiredOnServiceLocation" boolean NOT NULL DEFAULT FALSE,

    -- Number sequence starting values.
    "BillToStartNumber" BIGINT NOT NULL DEFAULT 100,
    "POStartNumber" BIGINT NOT NULL DEFAULT 100,
    "QuoteStartNumber" BIGINT NOT NULL DEFAULT 100,
    "WorkOrderStartNumber" BIGINT NOT NULL DEFAULT 100,

    -- Number prefixes.
    "InvoiceNumberPrefix" varchar(20) NULL,
    "QuoteNumberPrefix" varchar(20) NULL,
    "PONumberPrefix" varchar(20) NULL,
    "WorkOrderNumberPrefix" varchar(20) NULL,

    -- Invoice batch format.
    -- Examples:
    -- INV-{YYYY}-{0001}
    -- INV-{YY}-{MM}-{0001}
    "InvoiceBatchNumberFormat" varchar(200) NULL,

    -- Active/inactive status.
    "IsActive" boolean NOT NULL DEFAULT TRUE,

    -- Audit fields.
    "CreatedOn" timestamptz NOT NULL DEFAULT (timezone('utc', now())),
    "CreatedBy" uuid NULL,

    "UpdatedOn" timestamptz NULL,
    "UpdatedBy" uuid NULL,

    CONSTRAINT "PK_FgsTenantCompanyConfiguration"
        PRIMARY KEY ("TenantId", "CompanyId"),

    CONSTRAINT "FK_FgsTenantCompanyConfiguration_Tenant"
        FOREIGN KEY ("TenantId")
        REFERENCES "FgsTenant"("Id"),

    CONSTRAINT "FK_FgsTenantCompanyConfiguration_Company"
        FOREIGN KEY ("CompanyId")
        REFERENCES "FgsTenantCompany"("Id"),

    CONSTRAINT "FK_FgsTenantCompanyConfiguration_GloTimeCardOption"
        FOREIGN KEY ("TimeCardOptionId")
        REFERENCES "GloTimeCardOption"("Id"),

    CONSTRAINT "FK_FgsTenantCompanyConfiguration_GloAccountingIntegrationType"
        FOREIGN KEY ("AccountingIntegrationTypeId")
        REFERENCES "GloAccountingIntegrationType"("Id")
);
```

# 4. FgsLocation

Purpose:
Stores reusable address and geo-location information.

IMPORTANT:
Location ownership is handled directly using:
- MasterEntityTypeId
- EntityCode

## Table Structure

```sql
CREATE TABLE "FgsLocation"
(
    -- Primary location GUID.
    "Id" uuid PRIMARY KEY,

    -- Entity ownership type.
    -- Example:
    -- TENANT
    -- COMPANY
    -- BILLTO
    -- SERVICELOCATION
    "MasterEntityTypeId" INT NOT NULL,

    -- Entity/business code.
    -- Examples:
    -- BILL-1001
    -- WO-5002
    -- SITE-220
    "EntityCode" varchar(100) NOT NULL,

    -- Address lines.
    "AddressLine1" varchar(200) NULL,
    "AddressLine2" varchar(200) NULL,
    "AddressLine3" varchar(200) NULL,
    "AddressLine4" varchar(200) NULL,

    -- Regional information.
    "City" varchar(100) NULL,
    "State" varchar(100) NULL,
    "County" varchar(100) NULL,
    "Country" varchar(100) NULL,

    -- Postal/ZIP code.
    "PostalCode" varchar(20) NULL,

    -- Fully formatted address.
    "FormattedAddress" varchar(1000) NULL,

    -- Geo coordinates.
    "Latitude" DECIMAL(18,10) NULL,
    "Longitude" DECIMAL(18,10) NULL,

    -- Google/HERE place identifier.
    "PlaceId" varchar(500) NULL,

    -- Google validated address flag.
    "IsGoogleValidated" boolean NOT NULL DEFAULT FALSE,

    -- Customer manually validated address flag.
    "IsCustomerValidated" boolean NOT NULL DEFAULT FALSE,

    -- Active/inactive status.
    "IsActive" boolean NOT NULL DEFAULT TRUE,

    -- Audit fields.
    "CreatedOn" timestamptz NOT NULL DEFAULT (timezone('utc', now())),
    "CreatedBy" uuid NULL,

    "UpdatedOn" timestamptz NULL,
    "UpdatedBy" uuid NULL,

    CONSTRAINT "FK_FgsLocation_GloMasterEntityType"
        FOREIGN KEY ("MasterEntityTypeId")
        REFERENCES "GloMasterEntityType"("Id")
);
```

# 5. FgsCredentialProvider

Purpose:
Stores credential/integration metadata.

IMPORTANT:
- Actual secrets are NEVER stored in PostgreSQL.
- Secrets are stored in AWS Secrets Manager.
- This table stores metadata only.

Supports:
- global FGS credentials
- tenant-level credentials
- company-level credentials

## Table Structure

```sql
CREATE TABLE "FgsCredentialProvider"
(
    -- Primary credential provider GUID.
    "Id" uuid PRIMARY KEY,

    -- Optional tenant ownership.
    -- NULL = global/shared FGS credential.
    "TenantId" uuid NULL,

    -- Optional company ownership.
    "CompanyId" BIGINT NULL,

    -- Integration/provider type.
    "CredentialProviderTypeId" INT NOT NULL,

    -- Unique internal code.
    "Code" varchar(100) NOT NULL,

    -- Friendly display name.
    "Name" varchar(200) NOT NULL,

    -- Environment.
    -- Examples:
    -- PROD
    -- UAT
    -- DEV
    -- SANDBOX
    "Environment" varchar(50) NOT NULL,

    -- Description/notes.
    "Description" varchar(1000) NULL,

    -- Active/inactive status.
    "IsActive" boolean NOT NULL DEFAULT TRUE,

    -- Audit fields.
    "CreatedOn" timestamptz NOT NULL DEFAULT (timezone('utc', now())),
    "CreatedBy" uuid NULL,

    "UpdatedOn" timestamptz NULL,
    "UpdatedBy" uuid NULL,

    CONSTRAINT "FK_FgsCredentialProvider_Tenant"
        FOREIGN KEY ("TenantId")
        REFERENCES "FgsTenant"("Id"),

    CONSTRAINT "FK_FgsCredentialProvider_Company"
        FOREIGN KEY ("CompanyId")
        REFERENCES "FgsTenantCompany"("Id"),

    CONSTRAINT "FK_FgsCredentialProvider_GloCredentialProviderType"
        FOREIGN KEY ("CredentialProviderTypeId")
        REFERENCES "GloCredentialProviderType"("Id")
);
```

# 7. FgsCredentialSecret

Purpose:
Stores AWS Secrets Manager references.

IMPORTANT:
No actual secrets are stored in PostgreSQL.

## Table Structure

```sql
CREATE TABLE "FgsCredentialSecret"
(
    -- Primary secret GUID.

    -- AWS secret ARN.

    -- AWS region.

    "KmsKeyArn" varchar(1000) NULL,

    "RotationEnabled" boolean NOT NULL DEFAULT TRUE,

    -- Current version number.
    "VersionNo" INT NOT NULL DEFAULT 1,

    -- Last rotation timestamp.
    "RotatedOn" timestamptz NULL,

    -- Last validation timestamp.
    "LastValidatedOn" timestamptz NULL,

    -- Notes/remarks.
    "Remarks" varchar(1000) NULL,

    -- Active/inactive status.
    "IsActive" boolean NOT NULL DEFAULT TRUE,

    -- Audit fields.
    "CreatedOn" timestamptz NOT NULL DEFAULT (timezone('utc', now())),
    "CreatedBy" uuid NULL,

    "UpdatedOn" timestamptz NULL,
    "UpdatedBy" uuid NULL,

    CONSTRAINT "FK_FgsCredentialSecret_Provider"
```

# Developer Notes

1. Use CompanyGuid in APIs instead of internal Company Id.
2. Never expose sequential database IDs externally.
3. Use UTC timestamps everywhere.
4. Use IsActive instead of physical deletion.
5. Actual credentials/tokens must stay in AWS Secrets Manager.
6. PostgreSQL stores metadata and references only.
7. Company table stores identity/branding only.
8. Operational FSM behavior belongs in CompanyConfiguration.
9. FgsLocation supports polymorphic ownership using:
   - MasterEntityTypeId
   - EntityCode
10. Use AWS IAM roles instead of hardcoded AWS credentials.
11. Logo assets should be stored in AWS S3 + CloudFront.
12. WorkLocationRadiusForAutoArrive uses meters.
13. Configuration URLs/endpoints belong in:
    FgsCredentialProviderConfiguration
14. Global FGS credentials use:
    `"TenantId"` IS NULL
    AND `"CompanyId"` IS NULL
15. Apply `CREATE TABLE` in **dependency order** (e.g. `Glo*` catalog tables and `"FgsLocation"` before `"FgsTenant"` when foreign keys reference them).
